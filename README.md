# E-Commerce Store

A full-stack e-commerce web application built using Node.js, Express.js, HTML, CSS, and JavaScript.

## 🚀 Features

- Product listing page
- Product images
- Add to cart
- Remove from cart
- View total price
- Place order
- Login / Signup system

## 🛠 Tech Stack

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express.js

## 📂 Project Structure

ecommerce-app/
│── frontend/
│── images/
│── server.js
│── package.json

## ▶️ How to Run

1. Install dependencies

npm install

2. Start server

node server.js

3. Open frontend/index.html in browser
